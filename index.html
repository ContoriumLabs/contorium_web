One state system, multiple session views

IDE, MCP, and CLI are not separate memory systems — they are views over the same workspace state.

Workspace (filesystem) ↓ Contorium State Layer (.contora/) Session views (multi-client)
IDE windows MCP agents CLI processes AI tools

Session view — Each IDE window or AI agent is a view over the same underlying workspace state. They do not maintain separate memory. They observe different perspectives of the same state.

Contorium is not

  • A chat memory system
  • A prompt engineering tool
  • An AI agent framework
  • A tool integration layer

It is a workspace state system.

Why it matters

AI tools will continue to evolve. But project state should not depend on a single IDE, a single AI model, or a single session. Contorium makes project state portable across all tools and models.
