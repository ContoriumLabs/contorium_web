Project Intelligence Layer (PIL)

Contorium is built around a simple cognitive model — four core objects and five intelligence dimensions.

Core Objects

  • STATE — what exists now
  • INTENT — what the project is trying to achieve
  • DECISION — what was decided
  • WHY — why it was decided

Intelligence Dimensions

  • TIMELINE — how it evolved
  • IMPACT — what it affects
  • CONFIDENCE — reliability of understanding
  • EVOLUTION — structural changes over time
  • PROVENANCE — origin of knowledge

How it works

From connecting an AI tool to capturing new decisions — one continuous loop in your project folder.

1

AI agent connects

IDE, MCP, or CLI attaches to your workspace folder.

2

Contorium loads .contora/

Existing project intelligence is read from local artifacts.

3

State is reconstructed

Intent, decisions, and structure are rebuilt for the session.

4

AI inspects intelligence

Agents read context instead of asking you to re-explain.

5

Work continues

Development proceeds with full project understanding.

6

Decisions are captured

New focus, notes, and changes flow back into .contora/.

Install MCP Runtime

Run one command for your AI host, then open the tool in your project folder. Node.js 18+ required.

Optional npm install -g @contorium/mcp Faster cold start — or use npx @contorium/mcp directly
Codex Setup guide → 
codex mcp add contorium -- npx @contorium/mcp
Claude Code Setup guide → 
claude mcp add --scope project contorium -- npx @contorium/mcp
Cursor Setup guide →
  • Settings → MCP → Add server
  • Command: npx · Args: @contorium/mcp
  • Reload Window
