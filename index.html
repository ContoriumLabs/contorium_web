Five-layer runtime architecture

A structured cognition system — from persistent state to governed AI interaction.

01

Runtime Memory Layer

Persistent project state across sessions and tools — tasks, active work, intent, and recent changes.

02

Understanding Layer

Live analysis of changes, structure, dependencies, and hotspots in your workspace.

03

Knowledge Graph Layer

Structured cognition: Intent → Module → File → Function. AI sees relationships, not just files.

04

Governance Engine

Structured decision system with risk scoring, change reasoning, and multi-agent review — stored in .contora/governance/.

05

AI Interaction Layer

Controls how AI receives context — runtime snapshot, handoff system (Y/N), controlled injection, and export pipeline.
