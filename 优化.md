# ⚠️ Problem Section（为什么需要 Contorium）

```md
## AI coding tools forget your project

Modern AI coding tools are powerful — but stateless.

Every new session resets your context:

- You re-explain your architecture
- You re-describe decisions
- You re-state project intent
- You lose reasoning history
- You lose continuity between tools

Switching between Cursor, Claude Code, Codex, or Gemini CLI breaks understanding.

You are not missing intelligence.

You are missing persistence.
```

---

# 🧠 Solution Section（Contorium 是什么）

```md
## Contorium preserves project intelligence

Contorium introduces a persistent Project Intelligence Layer (PIL).

Instead of storing chat history, it stores structured project understanding:

- Current project state
- Project intent
- Architectural decisions
- Decision reasoning
- Evolution history
- Impact relationships
- Provenance & confidence

All stored locally inside your workspace:

.contora/
```

# 🧩 Core Concept（PIL）

```md
## Project Intelligence Layer (PIL)

Contorium is built around a simple cognitive model:

### Core Objects

- STATE — what exists now
- INTENT — what the project is trying to achieve
- DECISION — what was decided
- WHY — why it was decided

### Intelligence Dimensions

- TIMELINE — how it evolved
- IMPACT — what it affects
- CONFIDENCE — reliability of understanding
- EVOLUTION — structural changes over time
- PROVENANCE — origin of knowledge
```

# 🔄 How It Works

```md
## How it works

1. AI agent connects to workspace
2. Contorium loads `.contora/`
3. State is reconstructed
4. AI inspects project intelligence
5. Work continues with full context
6. New decisions are captured back into state
```

# 🔁 Transfer Concept（核心卖点）

```md
## AI continuity without re-explaining

Contorium enables seamless context transfer across AI tools.

### Transfer modes

- Transfer Context → quick continuation (~300–800 tokens)
- Transfer Intelligence → full project understanding (~8000 tokens)
- Transfer Handoff → runtime continuation (~100–300 tokens)

Switch tools without losing understanding:

Cursor → Claude Code → Codex → Gemini CLI
```
